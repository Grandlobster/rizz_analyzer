# RIZZ BOT
This project was made for personal rizz analysis based on my instagram chats with my ex-girlfriends and women in general the data was extracted using Instagram data export, an option available in Meta's account section.
It is based on simple principles
* message length by me vs the girl
* number of emojis used by girl
* and profanity
